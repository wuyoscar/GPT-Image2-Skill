## 设定要点
- 角色：以定妆图为准——黑发高髻、白发带白玉簪、多层白纱汉服；古剑"霜华"青玉剑鞘、银雕剑格、白剑穗。不加银白发尾与眉睫结霜。
- 妖怪：西游记式兽首人身（牛魔、猪妖、虎妖、狼妖、熊精、蛇妖、狐妖），持钢叉、朴刀、妖旗；禁用西式怪物。
- 色调：冷白灰蓝为主，黑红妖云对比，冰封后转血红。
