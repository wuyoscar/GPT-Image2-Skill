# AI 绘图提示词模板（角色 / 场景 / 道具）

> 用法：直接复制对应模板，把【】里的内容替换掉即可。一段到底，不需要分段编号。
> 全部用中文输出。角色为
>
> **精简版**
>
> （一段主体描述，无四宫格、无负面词、无英文指令）。



***

## 一、固定铁律（每次都要遵守）



1. 人物必须写：`中国男生/女生，亚洲面孔，东亚五官`，防止跑出欧美脸。

2. 皮肤必须写：`哑光妆效/哑光皮肤质感，无油光，不泛油`，杜绝油光满面。

3. 眼睛必须写：`双眼都睁开，对称双眼`，防止 wink、大小眼、闭眼。

4. 场景默认**空镜无人**，结尾负面词加 `人物，人，人脸`。

5. 不要每个场景都套同一套滤镜词，按时间段 / 情绪选不同胶片（见参数库）。

6. 少用空泛形容词（"高级感"" 氛围感 "），多写**具体物件、位置、材质、磨损、光线方向**。

## 三、场景提示词（空镜无人）

### 3.1 固定写作顺序



```
① 空间位置与整体结构（几段、几层、朝向、多大）

② 具体物件与布局（家具/道具写清位置、材质、新旧、磨损状态）

③ 光线（来源方向、色温、怎么落在物体上、影子多长）

④ 空气/声音/温度/气味（让画面"活"起来）

⑤ 摄影风格（导演/摄影师式，每次换一个，别重复）

⑥ 胶片型号与色调（查参数库，按时间/情绪选）

⑦ 镜头：焦段 + 光圈 + 景深
```

### 3.2 场景空白模板（复制填空）



```
【空间：什么地方，多大，结构，朝向】，

【物件1：位置+材质+新旧+具体状态】，

【物件2……】，

【光线：从哪来，什么颜色，怎么落，影子状态】，

【空气/声音/温度/气味】，

【摄影风格，如：是枝裕和式日常凝视 / 杜可风式室内光影】，

【胶片型号】胶片，【颗粒：细腻/中等/粗颗粒】，

【色调：暗部偏什么色，高光偏什么色】，

【】mm镜头，f/【】，【浅/深/极浅】景深，

## 四、道具提示词（单品展示）

### 结构



```
道具是什么+产品展示图 → 材质/尺寸/重量感 → 使用痕迹（磨损/划痕/掉漆/血迹）

→ 45度悬浮展示 → 纯色背景+打光方式 → 胶片质感+镜头 → 负面词（手、人物、全新）
```

### 示例



```
